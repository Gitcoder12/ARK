# CONTRIBUTING.MD

## Welcome to ARK
We are building better brakes for increasingly capable AI. Contributions are welcome from researchers, engineers, and alignment enthusiasts.

## How to Contribute
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/your-feature-name`.
3. Ensure your code passes all tests: `pytest -q`.
4. Ensure your code adheres to `Agents.MD` and `Skills.MD`.
5. Submit a Pull Request with a clear description of the change.

## Code Standards
- Python 3.10+, PEP 8.
- Type hints are mandatory.
- No `print()` statements; use `logging`.
- Every new feature requires a unit test.
