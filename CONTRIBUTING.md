# Contributing to ARK

Contributions should be small, reviewable and evidence-backed.

1. Read README.md, ACTIVITY_LOG.md and FEATURE_UPGRADE_PLAN.md.
2. Check current issues and PRs before duplicating work.
3. Choose one bounded task with acceptance criteria.
4. Work on a feature branch; do not commit directly to the default branch.
5. Add/update tests and user documentation with code changes.
6. Open a PR with exact commands, environment, results and limitations.
7. Append a dated activity-log entry after the work exists in a commit/PR.

Do not add secrets, private data or unlicensed datasets. Do not claim tests, benchmarks or deployment checks that were not performed. AI agents may inspect, implement and test scoped tasks; a human maintainer approves merges and deployments.
